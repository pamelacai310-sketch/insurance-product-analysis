# 最小抽取地图

先做文本/表格定位，只把命中的相关页交给模型理解。不要默认整份PDF进入长上下文。

| 目标字段 | 优先关键词 | 常见材料 |
|---|---|---|
| 保费/交费期 | 年交保险费、保险费、交费期间、交费方式 | 投保计划/利益演示 |
| 保证现金价值 | 现金价值、保证现金价值、退保金 | 现金价值表/利益演示 |
| 身故利益 | 身故保险金、身故给付、身故保险责任 | 利益演示/条款 |
| 减保 | 减少基本保险金额、减保、部分退保 | 条款/保全规则 |
| 保单贷款 | 保单贷款、借款 | 条款 |
| 非保证利益 | 红利、演示红利、万能账户、结算利率、非保证 | 利益演示/产品说明 |

## cheap-first顺序

1. 文件名/目录/文本层检索关键词；
2. 直接读取命中页的表格或文本；
3. 布局复杂或文本层失败时，仅对命中页做视觉读取；
4. 仅当字段仍冲突时，再扩大到相邻页或相关章节。

## core模式的年度抽取

- 从Y1开始顺序读取保证现金价值，直到首次出现GCV不低于累计保费；
- 额外读取Y5/Y10/Y20/Y30；
- 读取最长可用年度作为长期参考；
- 如果用户要“完整收益曲线/IRR稳定年度”，再升级为full模式。

## 证据记录

每组同页数据只保留一个 `source_ref`：文件、页码、章节、可选SHA-256。不要在JSON中重复粘贴整段条款。

## 冲突处理

以下情况停止自动结论并要求回查证据：

- 同一产品不同版本现金价值表不一致；
- 表头单位与数值量级矛盾；
- 保证与非保证列无法区分；
- 减保规则只出现在营销材料、正式条款没有对应依据；
- 同一比较组的投保场景不一致。
