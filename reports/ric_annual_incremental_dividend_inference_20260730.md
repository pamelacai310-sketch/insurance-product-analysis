# RIC当年度增额红利推测方法与适用边界

## 结论

图片中的正式利益演示对应：女性45周岁、5年交、保障至105周岁、第5个保单周年日起领取基本年金、65周岁起领取额外年金、基本保险金额100,000元、年交保费1,620,250元。费率反算为每千元基本保险金额16,202.5元，与RIC费率表相符。

该案例可以精确还原自身的非保证演示红利，也可以在**全部投保条件不变、仅基本保险金额或保费同比变化**时线性缩放；不能据此精确推导其他年龄、性别、交费期、保障期、首个年金领取日或额外年金领取年龄的红利。

“当年度增额红利”是当年新增的红利保额，不是保证现金收入。情景1逐年为0；情景2为非保证演示。实际红利只有取得保险公司年度红利通知后才属于已知数。

当年度值与累计值由保险公司分别对底层未展示小数取整，因此：

```text
累计红利(t) - 累计红利(t-1) ≈ 当年度红利(t)
```

相差1元属于展示取整，不应强制改写当年度原表值。

## 推测公式

若费率表口径为“每千元基本保险金额的年交保险费”：

```text
基本保险金额 B = 年交保费 P / 对应费率 r × 1,000
当年度演示增额红利 D(t) = 基准案例D_ref(t) × B / 100,000
历史实现率代理值 H(t) = D(t) × 历史实现率
```

第二个公式只允许用于与图片完全相同的投保组合。输出分为四级：

| 等级 | 数据来源 | 可否作为正式结果 |
|---|---|---|
| A | 该保单正式利益演示书直接列示 | 可作为非保证演示值 |
| B | 同投保组合按基本保险金额线性缩放 | 可作为核算估值，需提示舍入差异 |
| C | 演示值乘历史红利实现率 | 只能作历史敏感性代理，不能预测未来 |
| D | 跨年龄、性别、交费期或领取方案套用本案例 | 禁止输出伪精确结果 |

## 历史实现率

汇丰人寿披露：适用于2025年7月1日至2026年6月30日期间保单周年日的RIC增额红利实现率，2024年9月30日后递交保单为85.7%，此前递交保单为68.6%。2024年度披露的RIC实现率为68.6%。实现率定义为“实际派发的红利保额 / 红利利益演示的红利保额”，只能回顾历史，不能作为未来红利预期。

## 女32岁案例审计

此前案例为女性32周岁、5年交、年交保费46,168.80元，对应费率15,389.6元/每千元基本保险金额，因此基本保险金额为3,000元。但该案例选择保障至85周岁、50周岁起领取额外年金，与图片基准案例的保障至105周岁、65周岁起领取不同。

因此，现有图片只能证明该保单的保证红利为0、实际红利未知；不能把图片年度红利简单乘以3%作为正式结果。取得女32岁对应的正式利益演示书或该组合的增额红利演示因子后，才能生成逐年情景2红利。

## 使用方式

同一投保组合按基本保额估算：

```bash
python ric_dividend_estimator.py --basic-amount 100000 --format csv
```

由保费和费率换算，并附加85.7%历史敏感性代理：

```bash
python ric_dividend_estimator.py \
  --annual-premium 1620250 \
  --premium-rate-per-1000 16202.5 \
  --realization-rate 0.857
```

程序对不同投保组合直接报错，避免将单一案例错误推广。结果仅用于核算复核，不替代保险公司正式投保计划书或年度红利通知。
